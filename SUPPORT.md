# Support

Use GitHub Issues for setup questions, reproducible bugs, and focused feature requests. Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Include the revision, operating system, sanitized configuration shape, expected behavior, actual behavior, and minimal reproduction. Never post chat identifiers, message contents, credentials, tokens, transcripts, runtime databases, logs containing private data, signing material, or deployment secrets.

This is experimental software maintained on a best-effort basis. Operator-specific deployment and signing environments are not a supported public installation path.
